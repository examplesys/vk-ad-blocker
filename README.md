# vk-ad-blocker
Блокировщик рекламы в VK для Tampermonkey

## Блокируется:
- Рекомендации игр в ленте
- Рекомендация видео в ленте
- Любая реклама в блоке справа и слева
- Любые рекламные посты в ленте
- Любые рекламные посты в постах пабликов

## Известные проблемы
- Иногда лента может загрузиться пустой после фильтрации, лечится перезагрузкой страницы
